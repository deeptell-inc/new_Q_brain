## 【Critical 1】中心機構が実装されていない — レジスタは生成物ではなく「反応しなかった残り」

**両パネリストが独立に、コードから確認。確度 100%。**

- 箇所: `qbscreen/readout_routes.py:103–105`（持ち越し）, `:77–83`（部分トレース）
- 原稿の物語（Abstract L44–45, L312–315, Fig.1(b), SI §S7）は一貫して
  「核は再結合で消費されず、**反磁性生成物として去る**（$T_{1n}\sim0.1$–$1$ s）」。
- 実装は、サイクル終端の **trace-decreasing（＝再結合しなかった）** 状態を
  規格化して次周期へ渡し、その電子を部分トレースしてレジスタにしている。
  積分生成物核密度行列は**構築されていない**。
- 一方 CIDNP readout は docstring が明示するとおり「**再結合した**分子の分極」。
- **記憶と読み出しが互いに素な反応枝から取られ、同一分子として扱われている。**
  $k_S\tau\sim1$ なので持ち越されているのは「反応しなかった少数派」である。
- 帰結: 時計・register reuse・neural band——**Nature 級だと主張する結果の全部**——が
  この持ち越しに依存しており、現状の実行からは導けない。

**反証条件**: 次周期の `nuc` が $\int k_X \mathrm{Tr}_e[P_X\rho P_X]\,dt$ 型の
（三重項寄与込み・trace-preserving な）生成物密度行列として構築されている実行経路を示し、
その版で 2.008 / 4.650 と clock/reuse 曲線が再現されること。

## 【Critical 3】$\mathrm{MC}\times T_{\rm turnover}$ は memory horizon ではない

**両パネリストが独立に到達（A#2 ⊂ B-I）。確度 93–99%。**

- MC は無次元の二乗相関和で、**$d=0$ 項を含む**（`reservoir.py:203–212`）。
  よってメモリーレス系でも MC≈1 であり、$q=1$（毎サイクル完全消去）でも MC=1.002。
- 帰結: 記憶ゼロの系の「horizon」は $1\times T_{\rm cycle}$ となり、$T_{\rm cycle}$ と
  ともに**無限に増大する**。100 秒ターンオーバーの系は「100 秒の記憶 horizon」を持つ。
- したがって L357–358 の「bounded above by $\mathrm{MC}\times T_{1n}\sim1$ s」は
  定義から従わない。
- **Reviewer B の上乗せ（A の射程外）**: 同じ指標を本稿自身の量子優位性主張に適用すると
  **符号が反転する**。matched-hopping の非コヒーレント系は horizon = $1.0\times20\,\mu$s
  $=20\,\mu$s、コヒーレント系は $3.9\times50$ ns $=195$ ns で、**非コヒーレント側が
  100 倍勝つ**。
- **ファシリテータが独立確認**: `make_fig_criterion.py:51` は neural band を
  **10 ms–1 s** と描くが、Abstract と Conclusion は「3–280 ms, **inside** the neural
  band」と述べる。**3 ms は本稿自身の帯域の外側。**

**修正案**: horizon を $(\mathrm{MC}-1)\times T_{\rm cycle}$ か「カーネルが事前定義閾値を
切る遅延」として定義し直す。前者だと 100 ms 点で 180 ms（帯域内）、1 ms 点で
1.8 ms（**帯域外**）。

## 【Critical 4】核緩和チャネルが本稿内で二重定義され、正しい方を選ぶと結論が反転する

**Reviewer B のみの発見（A は完全に見落とし）。確度 92%。未検証。**
